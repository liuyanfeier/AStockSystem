# 业务能力路线

以[宪章](PROJECT_CHARTER.md)为目标，[当前能力](CURRENT_STATE.md)为起点。
Research V1～V3已走到真实公司研究；当前优先补持续判断、退出、组合风险和复盘。

|阶段|业务验收|依赖与边界|
|---|---|---|
|当前Decision Loop V0|三公司两次观察能解释事实变化、判断保留/暂停/失效复核、到期与下一人工动作；人工与模拟持仓分清|已有真实V2/V3和私有Journal；无持仓时UNKNOWN，无真实变化时明确模拟|
|日常运行验证|批准有限新行情后，持续使用收盘命令，价格/行业/资格和公告风险进入同一摘要|准确日期/成员/预算/实现授权；重点公告，不重建全历史平台|
|持仓与退出V1|实际持仓保留原逻辑、变更、退出复核和人工执行；组合风险可解释|私有快照、完整性/现金确认、批准风险参数；不按成本价机械卖出|
|交易计划与Journal V1|计划→新事实→判断→人工动作→退出→复盘；分析执行偏差和风险原因|A股约束与私有记录；观察退出、逻辑失效、风险退出和成交分开|
|策略验证V1|一个冻结Breakout/Pullback假设先前瞻/模拟，再补有限历史和样本外验证|T+1/停牌/涨跌停/跳空/费用/规则；不将当前上市池当无幸存者偏差资料|
|研究深化与持续使用|补改变判断的估值、竞争、产业/动态主题和催化；收盘/盘前摘要与条件提醒|由实际使用缺口驱动，不以更多候选/来源数量验收|

入场、退出、风险和复盘同步推进。没有真实持仓时先做观察/模拟，不据日志空宣称空仓。
允许不交易；风险批准是启用交易参数的前提，不是普通开发的逐步Gate。
下一步独立Review本批，再批准准确行情更新清单，用三案例检查真实新信息如何改变判断。
不重开Research V2治理，不将全历史Phase1完成作为当前观察研究前提。
容量目标50GB、上限100GB；日更只读链接旧Store，避免每天复制旧窗口。
迁移验证后移除旧实现，不削弱真实性、秘密或回归保护。旧路线见[历史索引](HISTORY.md)。
