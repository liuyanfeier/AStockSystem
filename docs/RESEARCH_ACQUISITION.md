# Research V1 近期行情预算（待用户批准）

目的：为“当前观察”获取近期连续行情，使默认20日收益/60日均线筛选有真实输入。
这是明确可批准的采集提案；本批调用0、execution_authorized=false，未实现/运行live采集命令。
不是全历史授权，不改旧消费/审批、不升级旧库、不下单。

## 固定范围

2026-04-01至2026-10-09，按返回交易日历验证连续性，目标至少120个交易日。
10月9日是本提案固定的待验证收盘截止日；如批准时需更新窗口，先更新具体请求清单，
不能在执行中静默扩大日期。当前交易日历未验证10月数据，不能保证该日开市或窗口一定120日。

默认观察池10只，仅作为分散行业的研究试点，不是用户持仓或推荐买入：
000001.SZ、000002.SZ、000333.SZ、002415.SZ、300750.SZ、600000.SH、600036.SH、
600519.SH、601318.SH、601899.SH。
基准000300.SH、000905.SH；通过index_basic真实身份验证，不能只靠字符串猜名称/交易所。
用户可批准整份范围或明确替换观察池；实际调用必须与最终批准清单一致。

| API | 次数上限 | 用途 |
|---|---:|---|
| daily、adj_factor | 各10 | 每股完整窗口日线和公司行为因子 |
| stk_limit、suspend_d | 各10 | 每股窗口限价、停牌证据；空稀疏状态不自动当正常 |
| index_daily、index_basic | 各2 | 两个基准连续日线及原生身份 |
| trade_cal | 2 | SSE/SZSE完整自然日窗口，检查开闭市/连续交易日 |
| stock_basic | 1 | 当前上市证券身份资料，筛出当次10股；不作历史身份全集 |
| stock_st | 1 | 固定行情截止日ST/风险警示；缺席保持UNKNOWN，除非有完整性证据 |
| 合计 | **48** | 每成员仅一次，无自动追加/分页/诊断调用 |

[机器可读请求清单](../config/research/acquisition-proposal.json)中的members明确params、fields、
已有契约hash；不是泛称48次后自由替换。可先复用已核验的本地来源减少实际调用，但不扩大总预算。
未获批准前不探测数据权限、不测试端点，也不请求最新股票/日历/行情。

## 执行和容量边界

- HTTPS POST https://api.tushare.pro；凭据仅从本机秘密设置读取，不写计划/HTTP来源/报告。
- 新目的地data/private/research-v1/capture-20261009；保留源响应与真实时间，不写旧原库。
- 最多48请求/48尝试，间隔至少1.25秒；retry=0、redirect=0。
- 单响应不超过2MiB，全部响应上限96MiB（100,663,296字节）；raw/typed/输入副本/报告新增
  磁盘上限256MiB（268,435,456字节）。这是保守上限，实际大小按捕获记录；不承诺恰好占满。
- 业务窗口约120×12根日线，加因子/限价和稀疏状态；不获取全公司财务/全历史修订。
- HTTP/权限/provider错误、响应上限/截断、泄密、身份/日期/单位冲突、不确定/滞留尝试即停止。
  保存失败与已消费状态，不重试或改名重跑；独立已完成离线分析可继续。
- 首批状态稀疏或无说明空返回保持UNKNOWN；不能凭无ST/停牌行保证可交易。
  新来源只验收CURRENT_OBSERVATION，不声明历史PIT、完整市场或交易资格。

最终已确认5个项目根约31.16GB文件分配空间（含旧工作目录和本批三个测试临时目录）；
其中本批测试临时产物约3.39GB单列，未手工删除。50GB目标、100GB上限仍适用；
采集前重查容量，不能靠遗漏外部目录或自动删不可替代数据满足预算。

批准所需内容已在本文件和请求清单中：观察池、两个基准、固定窗口、48次预算、端点、目的地、
256MiB新增磁盘与停止条件。实际执行尚需用户明确批准；普通软件开发无需新的逐步Gate。
